# Winter Olympics Data Analysis
Exploratory data analysis on Winter Olympics Data using PostgreSQL

**Tools Used:** Microsoft Excel, PostgreSQL  
**Skills:** Data Cleaning, SQL, Data Analysis, Performance Metrics, Efficiency Analysis

- Cleaned and preprocessed raw athlete and medal datasets using Microsoft Excel, ensuring data accuracy and consistency for analysis.
- Designed and executed over 10 structured PostgreSQL queries to explore trends in athlete participation, medal distribution, and country performance.
- Conducted efficiency analysis comparing medal counts to athlete participation, identifying countries with the highest conversion rates.
- Performed gender-based and age distribution analysis to uncover demographic patterns among medal winners.
- Prepared geographic and medal-type visualizations by aggregating medal data by country and event type.
- Delivered comprehensive insights on Olympic trends, aiding in performance benchmarking and strategic sports planning.
